# 视界 · 设计令牌与组件规格

设计基准：Figma 390 × 844。设计稿中的 1px 对应 `1.923076923rpx`，项目中统一通过
`dp(px)` 换算。令牌定义在 `shared/styles/tokens.scss`，由 `uni.scss` 全局注入。

## 5. 页面布局

### 5.1 发现页

- 顶部标题“发现”，右侧搜索、菜单；标题区高 56。
- 分类栏高 58，3 等分，列间 1px × 28 分隔线。
- 瀑布流：3 列、gap 8、左右 16、顶部 4、底部 20；卡片圆角 16。
- 卡片占 1 列或 2 列，由图片宽高与可选 `colSpan` 数据决定，绝对定位，
  容器高度动态计算。
- 底部自定义 TabBar：高 58 + 安全区。

### 5.2 个人空间

- 顶部标题“个人空间” + 菜单，高 56。
- 身份区左右 24：80 头像、24 昵称、@handle、34 高编辑资料胶囊、15 号 bio。
- 统计区：作品 / 粉丝 / 关注，值 24 粗体、标签 12，列间 1px × 28 分隔线。
- 分段控件高 46，外层 `#EFEFF2`，激活项为白色胶囊。
- 三列方形网格，gap 8；第二列整体下移 16，与发现页的瀑布流形成区分。
- 空态：收藏显示爱心图标，草稿显示文档图标，画廊显示图片图标。

### 5.3 编辑页

- 深色画布 `#121214`，状态栏浅色图标。
- Header 高 44，左右内边距 10：36 圆形返回 / 撤销 / 更多；文件名 13 号、最大宽 150、单行省略。
- 画布区：左右 16、上 8、下 12；照片圆角 14，完整显示（contain），双击在 1× / 2× 间切换。
- 沉浸预览：隐藏 Header、底部工具区和动作栏；画布铺满，轻触画面退出，双击放大。
- 底部操作区固定 218：工具轨 76 + 工具面板 142。
- 工具轨：6 个 44 圆形按钮，胶囊标签 10 号，左右内边距 22；激活态为 1.5 深色外描边。
- 工具面板：按当前工具切换，只替换面板内容，高度不变化；共享内边距 2 / 22 / 6。
- 底部动作栏：内容高 50 + 安全区；取消编辑 14 号、对比区 64 × 42、保存按钮 120 × 44。
- AI 面板：
  - 标题行 22，右侧“换图 / 预览 / 重置”；区域栏高 28、横向滚动。
  - 区域胶囊高 24、10 号字，圆点 6；最多展示面积前 12 个区域，加“全图”。
  - 强度行高 26，范围 0–100、默认 80，使用紧凑滑杆。
  - 风格缩略图 38 × 38、圆角 10、间距 7；激活 2px 橙色描边；横向可滚动。
  - 预设：还原、暖阳、冷冽、浓郁、黑白、复古、赛博；缩略图使用对应渐变和 CSS 滤镜。
  - AI 识别就绪时，画布常显低透明度区域蒙版；选中区域更明显，其他区域更淡。
  - 全图为底层，区域风格覆盖其上；每个区域独立记忆风格，“还原”删除该区域覆盖。
- 裁剪面板：自由 / 1:1 / 4:5 / 16:9；左转、右转、翻转。
- 调色面板：亮度 / 对比度 / 饱和度 / 色温，共用一根滑杆。
- 文字面板：38 高输入框、字号 12–64、5 个文字颜色、左中右对齐。
- 贴纸面板：8 个 emoji，横向滚动，可再次点击取消。
- 刷子面板：画笔 / 橡皮、大小 / 透明度分项、6 个颜色。

## 7. 图标与占位图

- 图标为自绘 Lucide 风格线性 SVG，统一导出为 96 × 96 PNG，避免 Android 对
  内联 SVG 的兼容差异；源文件在 `design/icons/`。
- 深色图标（`-dark`）用于浅色背景，白色图标（`-white`）用于深色画布，
  `-accent` 为橙红激活态，`-muted` 为次级灰色。
- 无图片时使用双层渐变 + 高光形状 + 细线的抽象占位，可叠加 aperture 水印；
  头像回退为首字母 + 渐变圆。
- App 图标：1024 × 1024 全出血橙色渐变 + 白色 aperture，由平台自行裁圆角。
